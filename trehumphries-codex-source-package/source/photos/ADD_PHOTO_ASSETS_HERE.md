# Photo asset drop location

Place the separately supplied `photo_assets.zip` in this directory as:

`source/photos/photo_assets.zip`

Codex should unpack and inventory it during the audit pass.

Selection rules:
- prioritize real project/client/product/working imagery over decorative filler
- do not use every image
- avoid weak, redundant, low-resolution, or off-brand photography
- preserve original files; make web-optimized derivatives during implementation rather than destructively editing sources
